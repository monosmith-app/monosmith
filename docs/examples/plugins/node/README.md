# node

The smallest smith **language plugin**, in Node.js with no dependencies and no SDK: it discovers
`widget.json` projects and gives each a cached `hello` task. Discovery only. The same program in
[`go`](../go) and [`python`](../python); a plugin with more methods and tests, on the TypeScript SDK, in
[`structure-layout-node`](../structure-layout-node).

```text
PS> smith plugin check .\plugin.cmd
```

Walk-through: [Writing a plugin in Go, Node.js or Python](../../../plugins/creating/plugin-sdks.md).

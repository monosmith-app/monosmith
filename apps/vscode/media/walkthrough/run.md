# Run a task

Press **Enter** on a task, or use **MonoSmith: Run Task** and pick a project and a task. The context menu runs all the tasks of a project, a group or a folder.

- The output streams to the MonoSmith output channel; `path:line:col` is a link.
- What failed (tsc, ESLint, go, ruff, rustc) lands in the **Problems** panel.
- **Show Task Output** on a row opens the last log of that task, also when it failed.
- **Cancel** (`Ctrl+Alt+M C`) stops the run and its processes.

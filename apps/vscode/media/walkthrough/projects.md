# Projects

The **MonoSmith** icon in the activity bar opens the projects of the workspace: apps, libs and packages, each with its language.

- A dot marks a project the changes affect. When every project is affected the dot is left out, since it would tell nothing, and the title says so.
- Open a project to see its tasks. A task shows how it ended and how long it took; hover for the cache hit and the last result.
- Filter the view with the search button, or show the affected projects only.
